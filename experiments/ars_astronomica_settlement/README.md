# Ars Astronomica equivariant settlement experiment

**Question:** Can recorded evidence settle a model family across Contexts while
future projection proceeds lawfully before settlement?

Two cycle models agree with a prior Observation, differ at one recorded occasion,
and make different later predictions. The model swap group is declared by Ars
Astronomica; the prior evidence leaves both models in its stabilizer.

## Success signal and observed results

- Spell capabilities are derived by elaboration under the Ars.
- Discrimination produces `Potential(family, settlement)`, not a stored option bag.
- Bright and dark Observations settle the same family to different model Points;
  irrelevant evidence preserves the identical Potential.
- Projection maps uniformly through the unsettled family, yielding a Potential of
  predictions. It does not inspect, branch on, reject, or settle the model frame.
- Shared, exchanged, and independent model frames preserve respectively two direct,
  two twisted, and four product correlations in this domain's local representation.
- Once evidence chooses a frame, the same projection produces a concrete Effect.
- Contradictory evidence and missing capability remain owned experimental results.

## Assumptions

- Predictions are declared symbolic Forms, not an astronomical simulator.
- The finite swap action and Python family graph are disposable representations.
- Evidence is a recorded Form; no clock, randomness, network, or external I/O exists.

Run with:

```console
python -m experiments.ars_astronomica_settlement
python -m pytest tests/experiments/test_ars_astronomica_settlement.py
```
