# State Zero Experiment 005: Virtual Mediation

**Question:** Can a mediator be operationally definite but unobserved while the frame
locating it remains genuinely unresolved, and can later evidence identify that frame
without retroactively changing the already-produced outcome?

The prompt is narrowly inspired by Stephen Mace's analogy between virtual mediation
and observable consequences attributed to omens or successful conjurations in
[*Sorcery as Virtual Mechanics*](https://www.scribd.com/doc/96245037/37606530-Stephen-Mace-Sorcery-as-Virtual-Mechanics).
This experiment does not assert that the occult or physical analogy is true. It asks
only whether the proposed mechanics expose representational distinctions.

## Neutral model first

`source_model.py`, `symmetry.py`, `mediation.py`, `observation.py`, and
`composition.py` use neutral domain terms. They define no classes named `Potential`,
`Point`, `Spell`, `Cast`, `Effect`, `Will`, or `Witness`, and import neither another
experiment nor `src/arx_mentis`.

The mechanism uses three cyclically related channels: alpha, beta, and gamma. Each
coordinate gives a definite but indirectly observed mediation trace. The complete
unresolved mechanics are carried by a lawful channel-indexed family.

## Assumptions

- This is a finite symbolic transfer mechanism, not physics and not evidence for an
  occult claim.
- Direct transfer is prohibited by the domain setup; a permitted channel mediates an
  equal aggregate transfer in every coordinate.
- The cyclic action and frozen Python graphs are disposable carriers.
- A signature identifies a channel under a declared observation law; an endpoint
  observation is deliberately non-discriminating.

## Success signal and executable witness

- Shared, one-step-twisted, and independent interactions have three, three, and nine
  joint results with distinct correlations.
- A naive option bag retains identical local options for all three and loses their
  relationship.
- Aggregate transfer becomes invariant without identifying the channel, while a
  lifted signature remains a three-way family.
- Later signature evidence identifies shared and twisted partners consistently but
  leaves an independent partner unresolved.
- Irrelevant and insufficient observations preserve the same structure;
  contradictory and undeclared observations remain explicit results.
- Endpoint acceptance succeeds without channel identification; a channel-specific
  criterion remains a nonconstant truth family.
- No channel is fixed by the cyclic action or justified by list position.

Run with:

```console
python -m experiments.virtual_mediation
python -m pytest tests/experiments/test_virtual_mediation.py
```

## Foundation mapping and friction

Only `foundation_mapping.py`, after the neutral model works, proposes correspondence
with the provisional foundation. It records rather than resolves the pressure that
one construction retains both a settled public outcome and an unresolved internal
mediation family. It also records the new distinction that indirect observability
and unresolved frame location are independent dimensions.

## Deletion or promotion path

Delete the family representation if the option-bag countermodel retains every tested
correlation, if uniform lifts choose a channel, or if later observations rewrite the
prior outcome. Promote only backend-neutral distinctions that pass the cross-domain
gate; never promote this Python API or Mace's motivating claim.
