# State Zero Experiment 009: Stress and Discharge

**Status:** Disposable evidence experiment. Nothing here is package API or accepted
language semantics.

## Question

Can a constrained system accumulate and discharge stress through a definite causal
mechanism without the discharge path or desired result being encoded in advance?

The motivating source is Stephen Mace's
[*Sorcery as Virtual Mechanics*](https://www.scribd.com/doc/96245037/37606530-Stephen-Mace-Sorcery-as-Virtual-Mechanics).
The experiment reconstructs only the neutral claim shape “stress resolves through an
event.” It makes no physical, psychological, magical, or occult causal claim.

## Assumptions

- A finite directed network can isolate distributed load, constraints, triggers,
  transfer, rupture, dissipation, oscillation, assessment, and history.
- Every link's capacity, conductance, threshold, and role is declared mechanics rather
  than a desired route.
- Frozen Python records are disposable carriers. Symbolic integers are not proposed
  units, probabilities, or runtime values.
- A deterministic mechanism may select a unique path only when declared structure
  distinguishes it. Exact ties return `AmbiguousDischarge` rather than use storage
  order.

## Mechanics

`StressField` records load by site. Gradual and sudden loading can reach the same
field with different histories. A `Trigger` merely opens the discharge process; the
field, topology, constraints, conductance, capacity, and transfer law determine what
happens next.

```text
distributed field + network + constraints + trigger + transfer law
    -> displacement | release | rupture | dissipation | oscillation
    -> historical residue
```

Partial discharge need not resolve the field. Mechanical resolution is assessed
separately from external acceptance, and lowering stored stress need not count as
progress toward delivery.

## Hostile countermodels

- **Single-number stress:** equal totals with different distributions take different
  first paths.
- **Target-coded discharge:** a preferred route is rejected as an outcome smuggled
  into its cause.
- **Trigger-only causation:** a trigger account is incomplete without field,
  topology, constraints, and transfer law.
- **Stress equals progress:** dissipation lowers stress while delivery remains zero.
- **Release erases history:** loading, rupture, displacement, release, dissipation,
  and oscillatory reversals remain in residue.
- **Blocked path equals no path:** blocking one route exposes another; only blocking
  every mechanically available route returns `NoDischargePath`.

Stored capacity is also rejected as a symmetry-indexed unresolved value. It constrains
transfer, contains unequal link roles, and encodes no candidate outcome.

## Success signal

The experiment succeeds if witnesses exercise gradual and sudden loading, distinct
paths from equal scalar totals, displacement, partial release, rupture, dissipation,
oscillation, retained residue, alternate and absent paths, separate resolution and
acceptance, and every hostile countermodel without importing foundation types.

## Result and boundary

The network demonstrates a definite causal discharge without a target argument.
Stress is distributed state, a trigger is one antecedent, discharge is a process,
resolution and acceptance are separate assessments, and historical residue survives
state change. The same stored capacity supports different paths because the current
field and constraints matter.

This does not establish a general stress algebra, a physical theory, a progress
metric, a foundation mapping, or a third witness for contextual reading or released
execution. No distinction from this experiment is promoted automatically.
