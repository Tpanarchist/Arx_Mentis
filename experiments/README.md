# Experiments

Experiments answer a named question and may be discarded. Begin each experiment with
its question, assumptions, success signal, and intended deletion or promotion path.
Do not import experiment code from `src/arx_mentis`, and do not treat an experiment's
Python API or behavior as an accepted language contract.

Record genuine design friction even when an experiment fails. Promotion into the
implementation still requires evidence, examples, tests, and a lowering sketch.
