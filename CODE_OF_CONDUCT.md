# Code of Conduct

We commit to a respectful, harassment-free project space. Discuss ideas and code
with curiosity, make technical criticism specific, and assume neither expertise nor
intent from identity. Harassment, threats, discriminatory language, and sustained
disruption are not acceptable.

Project maintainers may clarify, edit, hide, or reject contributions and may limit
participation to protect this standard. Report conduct or moderation concerns
privately to a maintainer through the repository host. Reports will be handled as
confidentially as practical.
